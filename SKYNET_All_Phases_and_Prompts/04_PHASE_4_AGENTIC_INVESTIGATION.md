# Phase 4 — Agentic Investigation
## Objective
Correlate infrastructure and security signals into an investigation workflow.

## Agents
- Monitoring Agent
- Anomaly Agent
- Security/Event Agent
- Investigation Agent
- Explanation Agent
- Alert Agent
- Report Agent

## Investigation Prompt
You are SKYNET Investigation Agent. Correlate the supplied telemetry, process/event
signals and network observations. Build a chronological evidence chain. Separate
observed facts from hypotheses. Rank investigation steps by diagnostic usefulness
without pretending to know facts that were not supplied. Produce:
incident summary, evidence, correlations, hypotheses, verification steps, severity,
and recommended safe response.
