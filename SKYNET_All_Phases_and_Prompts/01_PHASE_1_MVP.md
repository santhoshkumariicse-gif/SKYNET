# Phase 1 — Core Monitoring MVP
## Objective
Build reliable cross-platform telemetry for Windows PCs/laptops, servers and Android.

## Implement
- Device registration and authentication
- CPU, GPU, RAM, disk and network metrics
- Device heartbeat/online status
- Central API/database
- Basic dashboard
- Threshold alerts
- Historical metric storage

## Definition of Done
A live fleet of at least 3 devices can be monitored from one dashboard.

## Build Prompt
You are the lead systems engineer for SKYNET. Design and implement Phase 1 as a
production-minded MVP. Prefer modular services, secure device identity, efficient
telemetry, clear APIs and observable components. Return architecture, folder structure,
database schema, API contracts, implementation plan and test plan. Do not invent
features outside the phase.
