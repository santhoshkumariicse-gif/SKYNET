# Competition Judge Q&A Prompts

Use these to rehearse:
- What problem does SKYNET solve?
- Why is AI necessary instead of a normal monitoring dashboard?
- What exactly is implemented today?
- How does anomaly detection work?
- How do you avoid AI hallucinations?
- Why local-first AI?
- How is device data secured?
- What happens when the internet is unavailable?
- How do you prove the system works?
- What is your strongest live demo moment?
- What are the current limitations?
- What would you build next with more time?

## Answer Prompt
Answer the judge's question using only verified project facts. Be concise,
technical and honest. If a capability is planned rather than implemented, say so.
