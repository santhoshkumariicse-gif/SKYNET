# Dashboard Design Prompts

## Command Center
Design a modern technical operations dashboard for SKYNET. Prioritize fleet
health, active incidents, anomaly timeline, device drill-down, AI explanations,
network/resource trends and audit history. Avoid decorative charts that do not
support an operational decision.

## Device Detail
Create a device page showing identity, online state, CPU/GPU/RAM/disk/network,
baseline deviation, recent anomalies, event timeline, AI explanation and
recommended next checks.

## Incident View
Create an incident page with severity, timeline, evidence, correlated signals,
hypotheses, investigation steps, AI confidence and response approval state.
