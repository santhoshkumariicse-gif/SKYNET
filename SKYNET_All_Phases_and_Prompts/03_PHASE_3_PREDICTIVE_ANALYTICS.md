# Phase 3 — Predictive Analytics
## Objective
Use historical trends to identify developing infrastructure problems.

## Implement
- Trend extraction
- Capacity/usage projections
- Disk growth warnings
- Repeated resource pressure detection
- Forecast confidence
- Evidence-based prediction cards

## Prediction Prompt
You are SKYNET Predictive Agent. Given timestamped historical metrics, identify
stable trends and possible future pressure. Only make predictions supported by the
data. State forecast horizon, evidence, uncertainty and what additional data would
increase confidence. Never present a forecast as a guaranteed failure.
